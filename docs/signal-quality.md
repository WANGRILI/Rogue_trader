# Signal / Plan Lifecycle Quality

[中文](signal-quality.md) · [English](signal-quality.en.md)

RogueTrader 的每日输出不是彼此独立的定期预测，而是连续策略状态的一次更新。信号质量因此以参数化计划及其自然生命周期为单位，不再把每日评级强制延伸为固定 1/3/7/14/30 日样本。

## 评价协议

- 信号定义来自研究合格的 `参数化委托.csv`；触发、成交、止盈和止损来自同窗口的多因子逐小时执行回放。
- 计划从首个可执行 1H K 线开始，到下一份合格计划生效、计划到期或证据窗口结束为止。
- 新计划会更新策略状态；旧计划之后的行情不再回算到旧信号。历史隔离日不生成新计划，前一份有效计划自然延续。
- 每份计划以完全相同的期初现金和 BTC 持仓构造“原地不动”反事实：`生命周期价值增量 = 实际计划收益 − 原地不动收益`。
- 未触发条件只记录为未满足、到期或被替代，不作为亏损；每条委托的最终状态和完成时间另行输出。

这套指标评价的是包含条件、仓位与退出规则的完整计划更新，而不是纯方向 Forecast Alpha。手续费、滑点和历史组合状态会保留；整个 60 日 Portfolio PnL 仍是系统级最终验收结果。

```bash
ops/evaluate-signal-quality \
  --execution-result backtest/多因子版/<RUN_ID> \
  --ledger my_results/研究/参数化委托.csv \
  --window-start 2026-07-13T14:26:03+00:00 \
  --window-days 60
```

输出包含逐计划生命周期、逐委托生命周期、机器可读指标、中英文报告和 HTML 摘要。
